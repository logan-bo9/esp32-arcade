# ESP32 Arcade

Praktisches Projekt zum Aufbau eines kleinen Arcade-Automaten mit ESP32,
TFT-Display, Joystick, Tastern und Buzzer.

Die Idee entstand aus dem Interesse, wie die Technik hinter einem
Arcade-Automaten funktioniert. Gleichzeitig sollte ein persönliches Projekt
entstehen, das nach dem Aufbau nicht nur als Test dient, sondern tatsächlich
genutzt werden kann.

Im Mittelpunkt stehen der Aufbau und das Zusammenspiel der Hardware:
Displayausgabe, Eingaben, Verkabelung und die spätere Integration in ein
selbst konstruiertes Gehäuse. Die Spiele dienen als sichtbarer Funktionstest
für das gesamte System.

## Aufbau

- ESP32 als Steuerung
- 2,8-Zoll-TFT-Display
- Analog-Joystick
- Drei Taster
- Piezo-Buzzer
- Breadboard-Prototyp als Grundlage für das spätere Gehäuse

## Funktionen

- Menü zur Auswahl der Spiele
- Steuerung über Joystick und Taster
- Akustische Rückmeldung über den Buzzer
- Speicherung von Highscores
- Mehrere Spielmodi als Test für Bildschirm und Eingaben
